Detailed Architecture & Explanation of StudyFlow
Project Overview
StudyFlow is a Python-first, single-user agentic learning companion that creates personalized study plans, teaches concepts, generates quizzes, and adapts dynamically based on user performance. It uses LangGraph for stateful agent orchestration and SQLite for deterministic persistence.

3. Agent Nodes (The Learning Loop)
The Five Core Agents
┌─────────────┐    ┌──────────────┐    ┌─────────────┐
│   PLANNER   │──→│     TUTOR    │──→│  EVALUATOR  │
└─────────────┘    └──────────────┘    └─────────────┘
      │                       │                      │
      └───────────────────────┼──────────────────────┘
                                 ↓
                    ┌──────────┴──────────┐
                    ↓                       ↓
              [Continue]                   [Remediate]
Node Details
Planner Node (planner_node)
- Input: Plan, current step, topic
- Output: Next topic to study
- Prompt: "Create a short prerequisite-aware study plan as JSON"
- Behavior: 
- Returns empty plan → uses fallback (foundations of goal)
- Advances when current_step >= len(plan)
Tutor Node (tutor_node)
- Input: Topic, goal context
- Output: Lesson content
- Prompt: "Teach this topic for a beginner in concise format"
- Requirements: 
- Core idea explanation
- One concrete example
- Two self-check questions
Evaluator Node (evaluator_node)
- Input: Topic, lesson, user answer (if available)
- Output: Quiz + readiness score
- Behavior:
- Shows question if user_answer is empty or blank
- Tracks attempt count and answers
- Adaptive routing based on performance
Memory Node (memory_node)
- Input: Current step, session_id
- Output: Next step number
- Behavior: Persists progress to database
Focus Node (focus_node)
- Input: Session state
- Output: Warning message + event log
- Policy: "warn + soft-block" (monitors for distractions)
4. Database Schema
SQLite Tables
-- Sessions: Metadata about the session
CREATE TABLE sessions (
    session_id TEXT PRIMARY KEY,
    goal TEXT NOT NULL,
    duration_min INTEGER NOT NULL,
    content_sources_json TEXT NOT NULL,
    status TEXT NOT NULL,        -- "in_progress", "completed"
    created_at TEXT NOT NULL,
    completed_at TEXT
);

-- Session Events: Per-agent activity logs
CREATE TABLE session_events (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id TEXT NOT NULL,
    step INTEGER NOT NULL,
    agent TEXT NOT NULL,
    payload_json TEXT NOT NULL,
    created_at TEXT NOT NULL
);

-- Session Scores: Evaluation results
CREATE TABLE session_scores (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id TEXT NOT NULL,
    step INTEGER NOT NULL,
    topic TEXT NOT NULL,
    score REAL NOT NULL,        -- 0.0 to 1.0
    feedback TEXT NOT NULL,
    created_at TEXT NOT NULL
);

│    └──→ State updates: attempt_count = 1                │

│    ├─ Strong performance → END SESSION                     │
│    └─ Weak performance → CONTINUE TO NEXT TOPIC           │

6. Key Implementation Details
Type Hints & Contracts
State TypedDict:
class GraphState(TypedDict):
    # All fields are typed for IDE support and type checking
    session_id: str
    goal: str
    duration_min: int
    content_sources: list[str]
    current_step: int
    plan: list[str]
    current_topic: str | None
    lesson: str | None
    quiz: list[QuizItem]
    evaluation: EvaluationResult | None
    focus_events: list[str]
    messages: list[str]
    done: bool
    db_path: str
    live_updates: bool
Error Handling in Nodes
Fallback for bad JSON:
def _coerce_plan(data, goal):
    plan_raw = data.get("plan")
    if not isinstance(plan_raw, list):
        return ["Foundations of", "Core concepts of", "Practice"]
    # Clean and truncate to 5 topics max
    return [str(item).strip() for item in plan_raw]
Graceful degradation:
- If LLM returns empty response → uses fallback plan
- If JSON parsing fails → defaults to safe defaults
7. CLI Commands Explained
start-session
python -m studyflow.cli start-session \
  --goal "linear algebra" \
  --duration 30 \
  --sources generated,https://docs.python.org/3/howto/functional.html
Outputs:
- Generated study plan (JSON → human-readable)
- Lesson content from tutor agent
- Micro-quiz with readiness score
- Session metadata in SQLite
answer-quiz (M3 Feature)
python -m studyflow.cli answer-quiz \
  --session-id <session_id> \
  --question "What is linear algebra?" \
  --expected-answer "Linear algebra studies vectors..."
Outputs:
- Scored answer with feedback
- Adaptive routing decision (remediate/advance)
